# TechWise AI - Frontend Application

Next.js 16 (App Router + Turbopack) web interface for TechWise AI Laptop Shopping Assistant.

## Features
- **Liquid Glass Aesthetic**: Modern backdrop refraction, particle spheres, clean typography.
- **Voice Overlay**: Speech-to-text with real-time waveform visualization.
- **Laptop Evaluation & Comparison**: Plain language real-life metric cards (weight vs water bottles, battery life, screen clarity).

## Scripts
```bash
pnpm install
pnpm dev            # Run dev server on http://localhost:3000
pnpm build          # Next.js production build
```
