# TechWise AI - Backend Service

NestJS 12 Clean Architecture backend service for the TechWise AI Laptop Shopping Assistant.

## Features
- **Deterministic Recommendation Engine**: Multi-attribute ranking, budget/hardware constraints, scoring, trade-off generators.
- **AI Orchestrator & Tool Adapters**: Search, compare, benchmark lookup, review search.
- **Multi-Source Web Scraper**: Data extraction adapters for CellphoneS, GearVN, and PhongVu.

## Scripts
```bash
pnpm install
pnpm run start:dev  # Run dev server on http://localhost:4000
pnpm test           # Run unit tests (Vitest)
pnpm run build      # Build for production
```
